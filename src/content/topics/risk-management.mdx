# 風險管理

## 為什麼 TPM 要會？

風險管理不是每週問「有沒有風險」。TPM 要把不確定性具體化，定義觸發條件、影響範圍、預防動作與發生後的處理方案。

## 常見風險

- 外部 API 規格未定。
- 客戶測試資料延遲。
- RD 關鍵人力被抽走。
- 硬體、韌體、雲端、法規其中一段時程未對齊。
