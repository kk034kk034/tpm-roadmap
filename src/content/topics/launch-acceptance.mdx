# 上線與驗收

## 為什麼 TPM 要會？

上線不是按部署按鈕。TPM 要確保 release window、rollback、通知對象、監控項目、驗收證據與簽核流程都已對齊。

## Launch Plan

- Release scope
- Deployment window
- Owner and contact
- Rollback criteria
- Monitoring checklist
- Customer communication
- Acceptance evidence

## 驗收證據

保留測試結果、截圖、簽核紀錄、版本資訊與已知限制。這些資料會在後續維運、合約驗收與客戶溝通時非常重要。
